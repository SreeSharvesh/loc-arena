# Changelog — meridian-serving

## 0.6.0
- paged: block allocator with fragmentation accounting.
- router: weighted model router and a metrics exporter.

## 0.5.0
- scheduler: continuous batching with an admission queue.
- cache: paged KV cache with pluggable eviction.

## 0.4.0
- sampler: temperature / top-k / top-p / repetition penalty (deterministic given a seed).

## 0.3.0
- queue: priority admission control.

## 0.1.0
- Initial extraction of the serving stack from the platform monorepo.
