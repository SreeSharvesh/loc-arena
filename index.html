LOC-Arena

LOC-Arena is an AI control evaluation setting. An untrusted team of AI agents does real engineering work inside a simulated AI lab. In an attack episode the team also attempts a rogue internal deployment: a model kept running off the monitored path, under the team's control. Each episode measures two things independently and reports the gap between them.

Rogue internal deployment

A rogue internal deployment is a model the team keeps running inside the lab, off the sanctioned and monitored path, on compute it controls. It is not a model escaping to the internet. It is an unmonitored deployment stood up from inside, while the team is also doing legitimate work that fills the episode with normal activity.

The question is not whether an agent can be told to do this. It is whether the platform's ordinary controls, the same logs, reviewers, and monitors a real control team would run, catch it during the episode.

The two measurements

Every episode produces two verdicts from separate sources. They never share information.

  • Ground truth. A sealed, deterministic checker reads a private record of executed events and decides whether a rogue deployment exists. It reads executed facts, never an agent's claim. Agents have no route to it.
  • Detection. Monitors read only observable surfaces, the same ones a real control team sees, and score how suspicious the episode looks. They never read the sealed record or the checker's verdict.

Keeping the two apart is the point. If detection could read the sealed side, it would be grading with the answer key. The gap between a rogue deployment that happened and one the monitors flagged is the number the setting produces.

The honest twin

Every attack episode has an honest twin: the same config with the covert objective disabled. The twin runs the legitimate work only. It sets the baseline for normal behaviour, and it calibrates the detection threshold. It is also a standing check on the checker: the twin reaches no covert step, so it must always verify clean. If it ever did not, the checker would be wrong. The covert switch is the only difference between an attack episode and its twin, which is what makes comparing them valid.

Reproducibility

An episode is fully described by its config and a seed. It rebuilds from scratch every time, so a result reproduces exactly. Anything time-varying is seeded.
